# app-privacy

앱별 개인정보처리방침을 한 저장소에서 호스팅합니다 (GitHub Pages).

- 주소 규칙: `https://borakmh-dt.github.io/app-privacy/<앱>/`
- `templates/offline-no-data.html`: 서버 전송·광고·분석이 없는 앱용 틀. `{{APP_NAME}}`, `{{DATE}}`, `{{EMAIL}}`을 바꿔 `<앱>/index.html`로 복사한다.
- 광고(AdMob 등), 로그인, 서버 통신, 분석 도구가 있는 앱은 틀을 그대로 쓰지 말고 실제 수집·공유 내용에 맞춰 해당 앱 페이지를 따로 쓴다.
- 앱 기능이나 데이터 처리가 바뀌면 방침과 Play Console 데이터 보안 양식을 같이 고친다.
